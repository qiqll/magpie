## 记录格式

每条记录必须包含：任务 ID / 完成日期 / 一句话结论 / commit 列表 / 门禁结果 / 遗留项。
不写实现细节 —— 细节在 commit message 里。

```markdown
### T-NNN 任务标题
**完成：** YYYY-MM-DD · **优先级：** PN · **模块：** XXX
**结论：** 一句话说清做了什么、现在能用了吗。
**Commits：** `abc1234` 主实现 · `def5678` review 修复
**门禁：** code-reviewer 发现 H×1/M×2，H+M 已修，L×1 跳过（原因）· 测试 123 项全绿
**遗留：** 无 / 或列出转为新任务的 ID
```
